# Alternatives

[gh-dispatch](https://github.com/mdb/gh-dispatch) is a CLI that handles both `workflow_dispatch` and `repository_dispatch`, taking JSON payloads through command-line flags. Use it for scripting, CI, or `repository_dispatch` events. Use gh-lazydispatch for interactive exploration, frecency-based history, and guided input configuration.

- [chrisgavin/gh-dispatch](https://github.com/chrisgavin/gh-dispatch) is an interactive CLI for dispatching workflows with progress tracking
- [gh workflow run](https://cli.github.com/manual/gh_workflow_run) is the built-in `gh` command, with basic interactive prompts
- [nektos/act](https://github.com/nektos/act) runs GitHub Actions locally in Docker, which is local testing rather than remote dispatch
